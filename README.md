# 🌈 Tìm Lại Tuổi Thơ

Website dành cho những người muốn tìm lại ký ức tuổi thơ qua hoạt hình, siêu nhân và trò chơi huyền thoại.

## 📋 Nội Dung

- **📺 Hoạt Hình Tuổi Thơ** - Doraemon, Pokémon, Bakugan và nhiều bộ phim yêu thích
- **🦸 Siêu Nhân** - Super Sentai, Kamen Rider và các anh hùng huyền thoại
- **🎮 Trò Chơi** - Những tựa game gắn liền với tuổi thơ của nhiều thế hệ

## 🚀 Tính Năng

- Giao diện hiện đại, responsive trên mọi thiết bị
- Thanh điều hướng (Navbar) sticky
- Cuộn mượt (Smooth Scroll)
- Hiệu ứng animation khi cuộn trang
- Form liên hệ
- Design gradient đẹp mắt

## 📁 Cấu Trúc File

```
tim-lai-tuoi-tho/
├── index.html      # Trang chính
├── styles.css      # Stylesheet
├── script.js       # JavaScript
└── README.md       # File này
```

## 📝 Hướng Dùng

1. Clone repository:
```bash
git clone https://github.com/dinhnam112/tim-lai-tuoi-tho.git
```

2. Mở file `index.html` trong trình duyệt hoặc sử dụng Live Server:
```bash
# Nếu bạn có Live Server extension trong VS Code
# Nhấn chuột phải trên index.html → Open with Live Server
```

## 🎨 Công Nghệ Sử Dụng

- **HTML5** - Cấu trúc trang web
- **CSS3** - Styling và animation
- **JavaScript Vanilla** - Tương tác người dùng
- **Gradient** - Màu sắc hiện đại
- **Flexbox & Grid** - Layout responsive

## ✨ Đặc Điểm Nổi Bật

- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Hiệu ứng hover trên cards
- ✅ Smooth scroll khi nhấp vào menu
- ✅ Animation khi load trang
- ✅ Form liên hệ với validation
- ✅ Navbar sticky
- ✅ Intersection Observer cho animation on scroll

## 🌐 Triển Khai Online

### Sử dụng GitHub Pages

1. Đi đến Settings của repository
2. Tìm mục "GitHub Pages"
3. Chọn branch `main` và folder `/root`
4. Website sẽ được deploy tại: `https://dinhnam112.github.io/tim-lai-tuoi-tho/`

### Sử dụng Netlify

1. Kết nối GitHub với Netlify
2. Chọn repository `tim-lai-tuoi-tho`
3. Netlify sẽ tự động deploy
